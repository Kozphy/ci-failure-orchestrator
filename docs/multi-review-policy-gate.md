# Multi-review policy gate

The PR control plane combines heterogeneous review evidence before declaring a change ready.

```text
                 PR
                  |
        +---------+---------+
        |         |         |
        v         v         v
   CodeRabbit   Copilot   SonarQube
        |         |         |
     AI review  AI review  Static rules
        +---------+---------+
                  |
                  v
          Review Aggregator
                  |
                  v
            Policy Engine
                  |
                  v
       Independent Verification
                  |
                  v
          PR_READY / BLOCK
```

## Policy

The implementation is deliberately fail-closed. `PR_READY` requires all of the following:

- CodeRabbit review completed with evidence.
- Copilot review completed with evidence.
- SonarQube analysis completed with evidence.
- No HIGH or CRITICAL normalized finding.
- No provider finding explicitly marked blocking.
- Independent verification passed with non-empty evidence.

Missing, incomplete, or evidence-free controls produce `BLOCK`, not an implicit approval.

## Separation of concerns

`review_gate.py` owns normalized review models, aggregation, and deterministic policy evaluation. Provider-specific API collectors should translate external results into `ProviderReview`; they must not decide merge readiness themselves. Independent verification should be generated by a separate execution path from the agents that produced or reviewed the patch.

## Next integration step

Wire GitHub/CodeRabbit, Copilot, and SonarQube collectors into the normalized model, persist evidence using the run-scoped evidence store, and expose the final `PolicyDecision` as a required GitHub check. Provider outages and parse errors must produce incomplete reviews and therefore fail closed.

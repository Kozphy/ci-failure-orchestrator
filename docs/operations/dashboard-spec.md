# Dashboard specification (future only)

This document describes **future** panels. Phase 13 does **not** deploy a dashboard.

Suggested panels:

1. Run outcomes (workflow status distribution)
2. Automated run latency (median / p95)
3. Retry rate and stop-reason counts
4. Policy outcome distribution (not accuracy)
5. Security findings / blocks
6. Audit completeness
7. SLO status (MET / MISSED / INSUFFICIENT_DATA)

Data source: retained local artifacts / MetricsRecorder export.
No Grafana/Datadog deployment is included in Phase 13.

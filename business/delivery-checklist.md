# Delivery checklist

Use this for a real engagement. Nothing below has been checked off for a customer.

- [ ] Scope is one repository, at most five workflows, at most 30 runs.
- [ ] Access is an upload or a read-only token. The token was not sent in chat.
- [ ] Diagnosis command and its exit code are saved.
- [ ] Report has the thirteen sections. Unknown history is written as not measured.
- [ ] Each finding has an id, a policy-based severity, the log line, a heuristic confidence, a remediation, and `validation_status: not_executed` unless the client ran it.
- [ ] No reliability-improvement percentage is present.
- [ ] Secrets spotted in the output were redacted, and the client was told the redactor is not complete.
- [ ] JSON and Markdown were both delivered.
- [ ] Token revoked or the client confirmed revocation.
- [ ] One clarification reply was sent or the client asked for none.
- [ ] Hours spent are written on the scorecard only after the work happens.

# Landing page copy

Do not publish this as a claim of traction. There is no customer count to put on the page.

## Headline

Evidence-backed GitHub Actions failure diagnosis.

## Subhead

A free read-only Action for one saved log or one failed run. A US$149 written audit when you want a person to review up to five workflows.

## What you get from the Action

A category, the log line the classifier used, a heuristic confidence, and a recommendation marked not executed. No model API key.

## What you do not get

A guarantee of fewer failures, a dashboard, automatic merges, or a certification.

## Price

US$149 is a pilot price for the written scope in the repository file `business/service-offer.md`. It is not a price that has been validated by sales. Higher remediation work is not offered until that pilot has real demand.

## Call to action

Read the install guide and run the Action on a log you already have. For the paid audit, send sanitized logs. Do not send a personal access token.

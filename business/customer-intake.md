# Customer intake

Do not request a personal access token in email or chat.

## Questions

1. Repository URL and whether it is public.
2. Which workflows fail repeatedly, up to five names.
3. Roughly how often a failure blocks someone, in the client's own words. This is intake, not a measured metric.
4. Can they upload sanitized job logs? If yes, prefer that.
5. If not, can they create a fine-grained token with Actions: Read-only and Metadata: Read-only, one repository, expiry at most seven days, and revoke it after delivery?
6. Are they asking for a written diagnosis only, or for someone to open pull requests? Pull requests are outside this pilot.
